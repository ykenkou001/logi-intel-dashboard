## 4. 非機能制約

- **架空 URL 厳禁**: 一次資料 PDF が存在しない場合、推測 URL を返さず「未発見」と明示すること
- **古い改正版に注意**: 改善基準告示は 2024-04-01 で大幅改正されている。最新版を確認すること
- **告示原文 PDF を直接参照**: 解説記事ではなく、厚労省/国交省の公式 PDF を一次出典とする

---

## 5. Codex が迷ったら

- 「条文の存在は確認できるが番号が読み取れない」場合: 該当 PDF のページ番号 + URL を返す
- 「該当する記述が存在しない可能性がある」場合: その旨を明示し、近接する条文を代替案として提示
- 「最新版が見つからない」場合: 入手可能な最新版の日付と差分注記
- 不確実性があれば **必ず「推測」ラベルを付与**。Claude 側で `core/export/citation.py` への
  登録判断に使う

## 6. Claude 側の取り込みプロセス

Codex 回答受領後の段取り:

1. 「確定」ラベルの項目のみ `core/export/citation.py` に新規 `Citation` として登録
2. 「推測」ラベルの項目は memory `project_phase55_facility_followup.md` の §未確定リストに残し、
   `Facility.docstring` および `HeatmapResult.citations` には反映しない
3. 反映 PR を別途切る（タイトル例: `docs(facility): 寄託先関連の条文出典を citation に登録`）
4. 健一に出典 URL を 1-2 件踏ませて、PDF の該当ページに数値が記載されていることを確認させる
   （CLAUDE.md §7 検証ルール準拠）
