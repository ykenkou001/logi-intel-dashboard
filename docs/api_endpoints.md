# 利用 API 一覧・認証方法・キャッシュ設定

**責任範囲**: 各オープンデータ API のエンドポイント・認証・TTL・制約事項。新しい API クライアントを実装する前の必読ドキュメント。

---

## e-Stat API（政府統計）

| 項目 | 内容 |
|------|------|
| ベース URL | `https://api.e-stat.go.jp/rest/3.0/app/` |
| 認証 | クエリパラメータ `?appId=<アプリケーションID>`（"API キー"ではなく **アプリケーション ID**） |
| 登録 | https://www.e-stat.go.jp/a-2/ でユーザー登録後にアプリ登録（無料） |
| キャッシュ TTL | 24 時間 |
| バージョン | v3.0（2019-07-26 リリース、現行最新） |

### エンドポイント一覧

| エンドポイント | メソッド | 機能 |
|--------------|---------|------|
| `getStatsList` | GET | 統計表を検索してIDを取得（Step 1） |
| `getMetaInfo` | GET | 統計表のメタデータ取得（分類コード・時間軸・地域コード一覧）（Step 2） |
| `getStatsData` | GET | 実際の統計数値を取得（Step 3） |
| `postDataset` | POST | カスタムフィルタ条件を登録（再利用可） |
| `refDataset` | GET | 登録済みデータセットを参照 |
| `getDataCatalog` | GET | 統計ファイル・データベース情報を取得 |

### レスポンス形式の切り替え

| 形式 | URL パターン |
|------|------------|
| JSON（推奨） | `.../app/json/getStatsData?...` |
| XML（デフォルト） | `.../app/getStatsData?...` |
| JSONP | `.../app/jsonp/getStatsData?...` |

→ URL パスに `/json/` を挟むだけで切り替え可能。

### 主要パラメータ

#### 共通
| パラメータ | 必須 | 説明 |
|-----------|------|------|
| `appId` | ✓ | アプリケーション ID（環境変数 `ESTAT_APP_ID`） |
| `lang` | - | `J`=日本語（デフォルト）/ `E`=英語 |

#### getStatsList（統計表検索）
| パラメータ | 必須 | 説明 |
|-----------|------|------|
| `searchWord` | - | キーワード検索（例: `運輸業`） |
| `statsCode` | - | 省庁コード（例: `00200541`=経済センサス） |
| `surveyYears` | - | 調査年（例: `2020`） |
| `collectArea` | - | 調査地域（`1`=全国、`2`=都道府県、`3`=市区町村） |

#### getMetaInfo（メタデータ取得）
| パラメータ | 必須 | 説明 |
|-----------|------|------|
| `statsDataId` | ✓ | 統計表 ID（getStatsList の結果から取得） |

#### getStatsData（データ取得）
| パラメータ | 必須 | 説明 |
|-----------|------|------|
| `statsDataId` | ✓ | 統計表 ID |
| `cdCat01` | - | 分類事項1のコード（getMetaInfo で確認） |
| `cdCat02` | - | 分類事項2のコード |
| `cdArea` | - | 地域コード（例: `13000`=東京都） |
| `cdTime` | - | 時間軸コード |
| `startPosition` | - | 取得開始位置（ページネーション） |
| `limit` | - | 取得件数上限 |

### 3ステップ取得フロー

```
1. getStatsList(searchWord="運輸業") → statsDataId を取得
        ↓
2. getMetaInfo(statsDataId) → cdCat01, cdArea などのコード体系を把握
        ↓
3. getStatsData(statsDataId, cdArea="13000", ...) → 実際の数値取得
```

### エラーコード

| ステータス | 意味 |
|-----------|------|
| `0` | 正常完了（データあり） |
| `1` | 正常完了（該当データなし） |
| `100` | 認証失敗（appId 不正） |
| `101` | 必須パラメータ不足 |
| `102` | パラメータ値不正 |
| `200–203` | DB アクセスエラー |

### その他の注意事項

- パラメータ値は **UTF-8 URL エンコード**必須
- `Accept-Encoding: gzip` ヘッダーで圧縮レスポンス対応（大きな統計表で有効）
- HTTPS 必須（2018年1月以降）
- レートリミット: 公式未記載 → キャッシュ必須・バックオフ必須で対処
- コード → 名称変換: `getMetaInfo` のレスポンス内 `CLASS_OBJ` で対応表が取れる
- e-Stat の統計表 ID・コード体系の探索は `estat-explorer` サブエージェントに委譲

### `statsCode` と `statsDataId` の区別（実装時の必修事項）

| 用語 | 意味 | 例 | 安定性 |
|------|------|-----|--------|
| `statsCode`（省庁コード） | 統計分野・調査全体を識別する固定 ID | `00200552`（経済センサス）, `00600310`（賃金構造基本統計） | 安定（ほぼ変わらない） |
| `statsDataId`（統計表 ID） | 個別の統計表（特定年度・特定切り口）の ID | `0004005642`（経済センサス2021 産業別事業所数） | **毎年新しいIDが発行される** |

**実装ルール**:
- 統計表は `getStatsList(statsCode=...)` で**動的に最新の statsDataId を取得**してから `getStatsData(statsDataId=...)` を呼ぶ
- statsDataId をハードコードしない（例外: 5年に1回の特殊調査・経済センサス等で対象年度を固定したい場合のみ）
- 検索結果（statsCode → statsDataId のマッピング）は SQLite に 24 時間キャッシュ

### 物流関連の主要統計（statsCode 一覧）

| 統計 | statsCode | 用途 |
|------|-----------|------|
| 経済センサス‐活動調査 | `00200552` | 運輸業事業所数・売上（フェーズ1 の MVP ターゲット） |
| 国勢調査 | `00200521` | 道路貨物運送業就業者数（都道府県別） |
| 賃金構造基本統計 | `00600310` | ドライバー賃金推計用 |
| 自動車輸送統計年報 | `00600340` | 積載率・実車率の業界平均（フェーズ2.5 Step1） |
| 全国貨物純流動調査（物流センサス） | `00600370` | OD・モード別シェア（5年に1回・最新2021／フェーズ2.5 Step1） |
| 港湾統計 | `00600460` | モーダルシフト先キャパ（内航海運） |
| 鉄道輸送統計 | `00600420` | モーダルシフト先キャパ（鉄道貨物） |

## 燃料価格（gogo.gs）

| 項目 | 内容 |
|------|------|
| URL | `https://gogo.gs/`（トップページ HTML スクレイピング） |
| 認証 | なし |
| キャッシュ TTL | 24 時間 |
| 用途 | 全国平均ガソリン・軽油・灯油価格の取得 |
| 備考 | ユーザー申告集計データ。出典を「gogo.gs 全国平均」として明示すること |

### 注意事項

- `robots.txt` で ClaudeBot には `Crawl-delay: 10` のみ（Disallow なし）
- 過剰アクセス禁止（TTL 24 時間で運用）
- `.pref-price-panel > .average > label + .price` 構造に依存。ページ変更時は `_parse_gogogs_prices` 要修正

> ※ 資源エネルギー庁（enecho.meti.go.jp）は Akamai Bot Manager により本環境からアクセス不可（2026-05-01 確認）
