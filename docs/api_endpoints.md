# 利用 API 一覧・認証方法・キャッシュ設定

**責任範囲**: 各オープンデータ API のエンドポイント・認証・TTL・制約事項。新しい API クライアントを実装する前の必読ドキュメント。

---

## e-Stat API（政府統計）

| 項目 | 内容 |
|------|------|
| エンドポイント | `https://api.e-stat.go.jp/rest/3.0/app/json/` |
| 認証 | appId（無料、登録のみ） |
| キャッシュ TTL | 24 時間 |

### 注意事項

- コード → 名称解決が必要（地域コード、表章項目コード等）
- e-Stat の統計表 ID・コード体系の探索は `estat-explorer` サブエージェントに委譲

### 物流関連の主要統計表

| 統計表 | 用途 |
|--------|------|
| 経済センサス | 運輸業事業所数・売上 |
| 貨物地域流動調査 | 地域間貨物フロー |
| 賃金構造基本統計 | ドライバー賃金推計用 |

## RESAS API

| 項目 | 内容 |
|------|------|
| エンドポイント | `https://opendata.resas-portal.go.jp/api/v1/` |
| 認証 | `X-API-KEY` ヘッダー |
| キャッシュ TTL | 7 日 |

### 物流関連エンドポイント

- 産業構造マップ
- 人口動態
- 人流データ
- 消費データ

## 国税庁 法人番号 API

| 項目 | 内容 |
|------|------|
| エンドポイント | `https://api.houjin-bangou.nta.go.jp/4/` |
| 認証 | `applicationID` |
| キャッシュ TTL | 30 日 |
| 用途 | 都道府県別の運送会社リスト取得 |

---

## xROAD 交通量 API（JARTIC）

| 項目 | 内容 |
|------|------|
| エンドポイント | `https://api.jartic-open-traffic.org/geoserver` |
| 認証 | なし（利用規約同意のみ） |
| キャッシュ TTL | 1 分（5 分値データ） |

### 注意事項

- WFS 形式
- CQL filter で時間・地理範囲を絞る（過剰取得禁止）

## 気象庁 bosai JSON

| 項目 | 内容 |
|------|------|
| エンドポイント | `https://www.jma.go.jp/bosai/forecast/data/forecast/{area_code}.json` |
| 認証 | なし |
| キャッシュ TTL | 30 分 |

### 注意事項

- 商用利用は要確認（`docs/licenses.md` 参照）

## 資源エネルギー庁 石油情報

| 項目 | 内容 |
|------|------|
| 取得方法 | HTML スクレイピング（API なし） |
| 更新頻度 | 週次 |
| キャッシュ TTL | 7 日 |

### 注意事項

- スクレイピング規約遵守
- 過剰アクセス禁止（週次なので頻度低く実装）
