# 重要注意点

**責任範囲**: API 利用規約・シークレット管理・パフォーマンス制約・個人情報の扱い。実装時に常に意識すべき横断的な制約事項。

---

## API 利用規約

- 各 API の利用規約は `docs/licenses.md` に記録する
- 商用利用可否を必ず確認する（特に気象庁 JMA は要注意）
- 過剰アクセスは絶対に避ける（キャッシュ必須、リトライにバックオフ必須）
- 出典表記が必要な API は出力に明記する

---

## シークレット管理

- API キーは `.env` のみ（gitignore 済みを確認）
- ログに API キーを出力しない（マスク処理を `core/clients/base.py` で実装）
- `.env.example` に必要な環境変数のキー名のみ記載（値は記載しない）

---

## 個人情報の扱い

- 国税庁法人番号 API は法人情報（個人情報ではない）
- それ以外の API でも、個人特定可能なデータは取得しない

---

## パフォーマンス制約

- 開発マシンはメモリ 16GB — 大規模データの一括ロードは避ける
- DuckDB を使う場合も、必要な列・行に絞ったクエリを書く

---

## Zenn 記事執筆との連携

- フェーズ完了ごとに、実装ポイントを `docs/zenn_drafts/` にメモする
- スクリーンショット・コードスニペットも整理しておく
